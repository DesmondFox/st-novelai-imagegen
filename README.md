# NovelAI Image Gen (V4.5 / V5) для SillyTavern

Генерация картинок в NovelAI прямо из чата:

- модели **V5 Full / Curated**, **V4.5 Full / Curated**, V4 Full;
- **Furry mode**: добавляет тег `fur dataset` в начало промпта, как лапка в веб-интерфейсе NAI (отдельной фурри-модели у V4.5/V5 нет);
- **мультиперсонажность**: отдельный промпт и позиция на сетке A1–E5 для каждого персонажа (до 6);
- **единый стиль**: style-теги (с пресетами) идут в начало каждого промпта, LLM свои style-теги не добавляет;
- **сохранённая внешность**: теги внешности хранятся в карточке персонажа (и для вашей персоны) и подставляются автоматически. Кнопка «Заполнить из описания» делает теги из описания карточки или персоны;
- **внешность в чате**: когда LLM впервые описывает персонажа без сохранённых тегов, его внешность запоминается в чате и дальше подставляется кодом. Кнопка «Найти NPC в чате» сохраняет внешность всех описанных в истории NPC заранее. Если внешность изменилась по сюжету (причёска, шрам), кнопка «Обновить из чата» предлагает новые теги и после подтверждения сохраняет их в этом чате. Запись в чате важнее тегов карточки, сама карточка не меняется;
- **автосцена**: LLM читает чат и раскладывает сцену на фон и персонажей;
- **tool для LLM**: модель сама вызывает генерацию и умеет рисовать несколько картинок за раз («нарисуй 3 картинки…»).

Токен берётся из **API Connections → NovelAI**, тот же, что у встроенной генерации.

## Установка (Termux)

Нужны две части из этого же репозитория: серверный плагин и UI-расширение.

**1. Серверный плагин.** Запустите в Termux:

```bash
cd ~/SillyTavern
git clone https://github.com/DesmondFox/st-novelai-imagegen plugins/nai-imagegen
bash plugins/nai-imagegen/install.sh
```

`install.sh` включает `enableServerPlugins: true` в `config.yaml`. Если `config.yaml` ещё нет, сначала запустите SillyTavern один раз. SillyTavern сам обновляет плагин через `git pull` при каждом старте.

**2. Расширение.** Перезапустите SillyTavern, затем откройте Extensions → **Install extension** и вставьте:

```
https://github.com/DesmondFox/st-novelai-imagegen
```

Проверка: Extensions → **NovelAI Image Gen** → вверху должна быть надпись «✔ Серверный плагин подключён».

Серверный плагин нужен, потому что браузер не может ходить в `image.novelai.net` напрямую (CORS), а встроенный эндпоинт ST не передаёт промпты персонажей.

## Использование

**Команда**

```
/nai forest, night, campfire ; Seraphina> sitting, smiling @B3 ; 1boy, standing @D3
/nai count=3 orientation=landscape 1girl, beach, sunset
/nai model=nai-diffusion-4-5-full furry=true 1girl, wolf girl, forest
```

- Первый сегмент задаёт сцену: фон, свет, ракурс и число людей (`1girl 1boy`, `2girls`…).
- Сегменты через `;` описывают персонажей (используется `;`, потому что `|` в STscript служит пайпом).
- `Имя>` в начале сегмента подставляет сохранённую внешность этого персонажа.
- `@B3` задаёт позицию на сетке: A–E слева направо, 1–5 сверху вниз. Также понимаются `@left`, `@center` и `@right`. Без позиции модель расставит персонажей сама.

**Автосцена**: `/naiscene` (можно `count=2`), кнопка «NAI: нарисовать сцену» в меню волшебной палочки или кнопка в настройках.

**Картинка по запросу**: `/naiscene наш дом снаружи` или «NAI: нарисовать по запросу» в меню волшебной палочки. LLM рисует то, что попросили, а не текущий момент: место, предмет, персонажа в другой обстановке. Детали и внешность берутся из истории и сохранённых тегов. Если людей на картинке нет, персонажи не добавляются.

**Tool**: включите «Разрешить LLM вызывать генерацию». Также нужны:
- Chat Completion API, где модель поддерживает function calling;
- включённая галочка **Enable function calling** в настройках AI Response Configuration.

После этого можно просто написать «нарисуй нам 3 картинки у костра».

Картинки приходят отдельным сообщением-галереей. Это сообщение скрыто от LLM, чтобы теги не засоряли контекст ролевой игры.

## Бесплатные генерации (Opus)

Бесплатна генерация при таких условиях: 1 картинка за запрос, площадь не больше 1024×1024 и не больше 28 steps. Все три пресета размеров (832×1216, 1216×832, 1024×1024) укладываются в лимит. Несколько картинок генерируются последовательными запросами, поэтому тоже бесплатны.

## Что не проверено

- Настоящую генерацию в NovelAI я не запускал: для этого нужен токен. Цепочка ST → плагин → NovelAI проверена до ответа авторизации (401 на фейковый токен), а UI проверен с подменённым ответом.
- Quality-теги и негатив по умолчанию взяты из V4.5 Full. Для V5 официальные пресеты могут отличаться, поэтому оба поля редактируемые.
- Variety Boost отправляется только для V4/V4.5: константа для V5 неизвестна.
